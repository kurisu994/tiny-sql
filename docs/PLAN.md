# v0.6 开发计划

> 本节为 2026-08-24 起草的草案。V6-CP0（v0.5 用户验收清零 + 需求收口）完成后 Week 1 开工；等待期间只做文档级契约。

**周期与预算**：8 周，约 96-100h，按作者业余时间 12-13h/周。

**定位**：v0.6 的主题是「结构对比、可审阅同步与关系图」。在 v0.5 已能改单库结构之后，让作者对着 prod / staging 两套连接看清差异（FR-220，P0），再生成可审阅的结构同步脚本（FR-261，P1，默认不自动执行），并补上只读 ER（FR-263，P1）。完整范围以 [ROADMAP v0.6](./ROADMAP.md#v06--结构对比可审阅同步与关系图) 与 [REQUIREMENTS §3.6](./REQUIREMENTS.md#36-v06-范围结构对比可审阅同步与关系图) 为准。

**为什么不把原 v0.6+ 整包塞进来**：数据传输、用户权限、BI/AI 各自是另一条产品线。8 周只扛「1 个不降级 P0 + 2 个可降级 P1」。

| ID | 功能 | 优先级 | 版本内地位 |
|---|---|---|---|
| FR-220 | 双连接结构 diff（库 / 表 / 列 / 索引 / 约束） | P0 | 不降级 |
| FR-261 | 由 diff 生成可审阅结构同步 SQL | P1 | 可降级「只生成不执行」；不做数据拷贝 |
| FR-263 | 只读 ER（由已有 FK 元数据） | P1 | 可降级整项 |

## V6.2 时间线与依赖顺序

```text
Phase 0  前置  v0.5 验收清零 + v0.6 需求收口（不计入 8 周）
Week 1  13h  结构快照与差量模型：表/列/索引/约束双方言（FR-220 内核）
Week 2  13h  双连接选择 + 对象列表 diff UI（FR-220 前半）
Week 3  12h  列/索引/约束明细对比 + 导出报告（FR-220 收口）
Week 4  12h  由 diff 生成结构同步 SQL（FR-261 前半）
Week 5  12h  脚本预览确认执行 + 失败定位（FR-261 后半）
Week 6  13h  只读 ER：FK 构图、节点/边、点击定位（FR-263 前半）
Week 7  12h  ER 布局/筛选打磨 + 双方言回归（FR-263 后半）
Week 8  12h  双连接 dogfooding + 文档 + RC / 正式发布

合计约 99h；P0（FR-220）目标 Week 1-3 完成。
```

关键依赖链：

1. 已有 `list_tables` / `list_columns` / `list_indexes` / `list_constraints` + 打开多条连接 → 结构快照。不新开「同步协议」契约，diff 是应用层组合。
2. AppState 已按 connection_id 注册多条 `OpenConnection` → 左右两侧各用一条已打开连接，不隐式重连、不串 session。
3. v0.5 `ddl.ts` ALTER / 索引 SQL → 同步脚本生成复用同一套标识符与白名单；执行走 `db_query` / `db_query_many` 写确认。
4. ER 只读消费 FR-241 外键元数据，不做正向工程、不手动画线落盘。

## V6.5 测试矩阵

- **diff 矩阵**：仅左 / 仅右 / 列类型变更 / 默认值 / 索引列序 / 复合主键；MySQL 与 PG 各自一对连接。
- **同步矩阵**：生成 SQL 与手工预期一致；跨 driver 拒绝生成；执行失败定位；确认框含完整文本。
- **ER 矩阵**：无 FK 库不崩；自引用；复合外键；点击定位。

## V6.6 主要风险

| 风险 ID | 描述 | 影响 | 缓解 |
|---|---|---|---|
| V6-R01 | 误把 staging 脚本打到生产 | 高 | 确认框写明目标连接名 + 完整 SQL；默认不自动执行 |
| V6-R02 | 两边元数据快照时间差造成假差异 | 中 | 每次对比重新拉；界面显示快照时间 |
| V6-R03 | MySQL vs PG 类型无法机械对齐 | 高 | 跨 driver 只展示不生成脚本 |
| V6-R04 | DDL 执行无法整体回滚 | 高 | 失败如实报告已执行序号；引导用官方备份 |
| V6-R05 | ER 大库卡死 | 中 | 先做当前 schema；超过阈值提示筛选 |
| V6-R06 | 数据同步 / 权限 / AI 范围膨胀 | 中 | 明确不做；Week 7 后不加新 FR |

明确不进入 v0.6：数据传输 / 行级同步、用户权限（FR-262）、BI / AI、自动执行无预览的破坏性变更、跨 driver 一键同步、应用内账号。

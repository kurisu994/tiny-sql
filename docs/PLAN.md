# v0.5 开发计划

> 本节为 2026-08-24 起草的草案。V5-CP0（v0.4.0 正式发布 + 无阻塞补丁 + 需求收口）全部完成后，v0.5 Week 1 才开工。RC / 发布等待期间只做文档级契约设计。

**周期与预算**：8 周，约 96-100h，按作者业余时间 12-13h/周。

**定位**：v0.5 的主题是「结构变更、官方备份与连接协作」。在 v0.4 已能看结构、新建表、改行数据之后，补上日常改表（FR-253，P0），再用官方客户端做可恢复备份（FR-260，P1），并补上从 v0.1 就欠着的加密分享连接（FR-221，P1）。完整范围以 [ROADMAP v0.5](./ROADMAP.md#v05--结构变更官方备份与连接协作) 与 [REQUIREMENTS §3.5](./REQUIREMENTS.md#35-v05-范围结构变更官方备份与连接协作) 为准。

**为什么不把 ROADMAP 的 v0.5+ 整包塞进来**：FR-261 同步依赖尚未存在的多集群 diff（FR-220），FR-262 用户权限是另一套管理面，ER / BI / AI 是 P2。8 周业余时间只扛得住「1 个不降级 P0 + 2 个可降级 P1」，与 v0.3 / v0.4 同一节奏。

| ID | 功能 | 优先级 | 版本内地位 |
|---|---|---|---|
| FR-253 | 修改表 + 索引 / 约束设计器 + View 结构 | P0 | 不降级（列级 ALTER 必须交付） |

- **V5-T4.1 [4h]** 工具探测：设置项或 PATH 查找 `mysqldump`（必做）与 `pg_dump`（争取）；版本打印进日志；找不到则明确错误，**禁止静默回退成 FR-252 dump**（那不是备份格式）。
- **V5-T4.2 [5h]** 通过现有隧道本地端口拉备份：后端拼命令，凭据写入临时 defaults file / `.pgpass`（0600），**禁止出现在 argv**；stdout 流式写入用户选的文件；cancel token 杀子进程。
- **V5-T4.3 [3h]** 进度：至少「已写入字节 + 运行中/取消/失败」；失败保留日志摘要（截断、无密码）。范围：当前 library/schema 或单表，不做全实例 `--all-databases`。

### v0.5 Week 6 — 连接分享导出（13h）

- **V5-T6.1 [5h]** 分享信封：独立口令 Argon2id → AES-256-GCM；文件自描述（版本 / 盐 / nonce / 密文），不含 `master.key`、不含本机 `security.json` verifier。
- **V5-T6.2 [4h]** 导出 UI：多选连接；默认只带连接字段与 hop 口令，**私钥文件内容默认不打包**（只保留路径，导入方本机要有同一把钥匙）；勾选「包含私钥内容」必须二次警告。
- **V5-T6.3 [4h]** 导出单测：错误口令打不开；篡改密文拒绝；明文文件 grep 不到密码。

验收：分享文件离开本机后，没有分享口令无法还原任何 secret。

### v0.5 Week 7 — 连接分享导入（12h）

- **V5-T7.2 [4h]** 重名策略：允许并存（名称加后缀）或让用户改名；导入失败不写一半。主密码锁定时拒绝导入。
- **V5-T7.3 [3h]** 与 TOFU 的关系：导入不带入对方 `known_hosts`；首次连接仍走本机指纹确认。

验收：**V5-CP4** 作者机导出 → 另一配置导入，3 跳连接字段完整且 secret 可用。
